# Domain docs

This is a single-context repository.

Before exploring the codebase:

- Read `GLOSSARY.md` when it exists.
- Read relevant ADRs under `docs/adr/`.
- Proceed silently when these files do not exist.
- Use glossary terminology consistently.
- Surface conflicts with existing ADRs explicitly.

The glossary and ADRs are created lazily as decisions are made.
