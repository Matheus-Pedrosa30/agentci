# Issue tracker: GitHub

Issues and specs live in GitHub Issues for `Matheus-Pedrosa30/agentci`. Use the `gh` CLI for operations.

- Create, read, edit, comment on and close issues with `gh issue`.
- Infer the repository from the Git remote.
- Use GitHub sub-issues and native dependencies when available.
- Publish specs and tickets as GitHub Issues.
- PRs are not treated as incoming requests for triage.
- Wayfinder maps use a parent issue with child decision issues.
- Never create issues outside the user's repository.
